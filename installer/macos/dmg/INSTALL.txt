Install or update Mandarin, by Tage
Drag Mandarin onto Applications. To update, drag the new version onto Applications
and replace the old one; there is no need to remove it first.

First launch
This build is not notarized. If macOS blocks the first launch, open
System Settings > Privacy & Security and click Open Anyway. Only open a build
whose source and checksum you trust.
Mandarin lives in the menu bar (no Dock icon). Its menu has Settings,
Enable / Disable, Launch at Login, About and Quit.

Permissions
Allow Mandarin in System Settings > Privacy & Security > Accessibility AND
Input Monitoring, then quit Mandarin from its menu bar icon and open it again.
After an update, macOS may still list Mandarin switched on while the wheel
doesn't open: select Mandarin there, remove it with the - button, then add
Mandarin.app again with + and switch it on.
Allow Finder under Automation when using a selection shortcut.

Using it
Select files in Finder, start dragging them, hold Command and the wheel opens.
Drop on a slice (Command may stay held). Tab flips to the other side.
